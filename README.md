 # Online Sales Analysis

## Opis

Ovaj projekat omogućava upravljanje proizvodima i analiziranje online prodaje. Sadrži klase za proizvode, menadžera proizvoda i korpu kupca.

## Klase

### Product
- **Atributi**: `name`, `price`, `quantity`
- **Metode**: `display_info()`, `update_quantity()`

### ProductManager
- **Atributi**: `products`
- **Metode**: `add_product()`, `display_products()`, `total_inventory_value()`

### Cart
- **Atributi**: `cart_items`
- **Metode**: `add_to_cart()`, `total_cart_value()`, `display_cart()`
